# Nexa AI Chatbot

An AI-powered chatbot web application designed to provide interactive conversations and help users analyze uploaded documents and images.

## Features

- AI-powered conversations and follow-up questions
- Chat history saved in the browser
- Create, rename, and delete conversations
- Regenerate AI responses
- Copy AI messages
- PDF document upload and analysis
- Image upload and analysis
- Responsive user interface for desktop, tablet, and mobile
- Frontend and backend deployment

## Technologies Used

### Frontend
- React
- Vite
- JavaScript
- Lucide React
- PDF.js

### Backend
- Cloudflare Workers
- AI API integration

### Deployment
- Vercel — Frontend
- Cloudflare Workers — Backend
- GitHub — Source code repository

## Getting Started

### Prerequisites
- Node.js and npm
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/hiramansha/Nexa_Ai_Chatbot.git
   ```

2. Open the project directory:

   ```bash
   cd Nexa_Ai_Chatbot
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL provided by Vite in your browser.
